# Engine compatibility

Requires Lua Platform, core mod `ccb`, `on_item_description_append`, and `on_item_ascii_art_fallback`. Stock versions without these hooks cannot load this MOD.

Candidate engine base: `32a2a03425aed2de13d1aa38c698f843d29f3ba2`, plus the separately supplied hook patch. The MOD ZIP does not contain the engine. Compatibility with every CPH revision is not claimed. Runtime acceptance is recorded separately against exact package and engine bytes.
